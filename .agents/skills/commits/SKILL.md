# Commit messages

- Write the commit subject and body in English, regardless of the conversation language.
- Use a short, descriptive subject in the imperative mood, such as "Add a post about AI in everyday life" or "Remove the sample Hello World post".
- Describe the actual change. Add a body only when it helps explain the reason or relevant context.
- Check the changed files and the proposed message before committing.
- Keep blog content in its intended language; this rule applies to commit messages.
- Apply this rule to future commits. Do not rewrite existing commit history unless the user explicitly requests it.
